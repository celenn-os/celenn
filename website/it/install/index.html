Installare cosmic-blue passo passo

Calcolate mezz'ora. Potete provare cosmic-blue prima dalla chiavetta USB: sul computer non cambia nulla finché non avviate l'installazione.

Chiavetta USB da 8 GBverrà cancellata
64 GB di disco128 GB consigliati
4 GB di memoria8 GB consigliati
PC a 64 bitIntel o AMD

  1. Fate un backup dei file

    Copiate documenti e foto su un disco esterno o online. Fatelo anche se tenete Windows: un errore sul disco capita in fretta.

  2. Scaricate la versione giusta

    Una scheda grafica NVIDIA (GeForce GTX 16xx, RTX)? Prendete la versione NVIDIA, altrimenti quella standard. Per saperlo, in Windows: Gestione dispositivi → Schede video.

    Scarica

  3. Preparate la chiavetta

    Installate Fedora Media Writer (Windows o Mac), scegliete Seleziona file .iso, poi la chiavetta, poi Scrivi.

  4. Avviate dalla chiavetta

    Con la chiavetta inserita, accendete il computer premendo più volte il tasto della vostra marca, poi scegliete la chiavetta USB.

    MarcaTasto
    Acer, Dell, LenovoF12
    HPF9 / Esc
    ASUSF8 / Esc
    MSIF11
    AltraF12, F11 / Esc

    Non funziona? Da Windows: Impostazioni → Sistema → Ripristino → Avvio avanzato → Riavvia ora, poi Usa un dispositivo.

  5. Provate, poi installate

    Il desktop di cosmic-blue parte dalla chiavetta. Controllate Wi-Fi, audio e schermo. Se va tutto bene, aprite Install cosmic-blue sul desktop.

  6. Scegliete dove installare

    Sostituire Windows il più semplice

    Nel programma di installazione scegliete il disco e liberate spazio eliminando tutto. L'intero disco viene cancellato.

    Accanto a Windows

    Prima, in Windows, aprite Gestione disco, cliccate col tasto destro sulla partizione di Windows e scegliete Riduci volume per liberare almeno 64 GB. Il programma di installazione userà poi da solo quello spazio libero.

    Prima di ridurre, disattivate la crittografia in Windows: Impostazioni → Privacy e sicurezza → Crittografia dispositivo (o BitLocker). Un secondo disco solo per cosmic-blue è ancora più semplice.

    Poi cosmic-blue parte per impostazione predefinita. Per avviare Windows, usate il tasto del passo 4 e scegliete Windows Boot Manager.

  7. Versione NVIDIA: una schermata blu al primo riavvio

    È normale e succede una sola volta, con Secure Boot attivo: permette di caricare il driver NVIDIA. Usate le frecce e Invio. La password è cosmicblue (la tastiera può essere in QWERTY inglese).

    Saltata? Il desktop parte comunque, senza il driver NVIDIA. Aprite Strumenti di cosmic-blue → Computer, cliccate su Consenti e riavviate.

  8. Benvenuti

    Dopo il riavvio, create il vostro account. Si apre poi il tour, che vi aiuta a sistemare tutto.

cosmic-blue è costruito su Universal Blue, Bluefin, Fedora e COSMIC. cosmic-blue è un progetto indipendente, non affiliato a questi progetti né approvato da essi.
