Installazione

Pronto in circa mezz’ora

Provalo prima dalla chiavetta USB: sul computer non cambia nulla finché non avvii l’installazione.

  1. Scarica la ISO

    La versione per AMD o Intel, oppure quella NVIDIA con il driver già installato.

  2. Crea la chiavetta USB

    Con Fedora Media Writer, su Windows, Mac o Linux.

  3. Prova, poi installa

    Il desktop si avvia dalla chiavetta. Quando tutto funziona, avvia il programma di installazione.

Usi già Bluefin, Aurora, Bazzite o Fedora Atomic? Passa a cosmic-blue senza reinstallare. 
ujust enroll-secure-boot-key   # solo se Secure Boot è attivo
    sudo bootc switch ghcr.io/cosmic-blue-os/cosmic-blue:stable
    sudo systemctl reboot

Dopo il riavvio, cosmic-blue attiva da solo il controllo della firma dei suoi aggiornamenti. stable avanza una volta a settimana; passa a testing per avere ogni build giornaliera, o a dev per ogni modifica appena viene integrata.
