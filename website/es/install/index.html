Instalar cosmic-blue paso a paso

Calcule media hora. Puede probar cosmic-blue primero desde la memoria USB: nada cambia en el ordenador hasta que inicie la instalación.

Memoria USB de 8 GBse borrará
64 GB de disco128 GB recomendados
4 GB de memoria8 GB recomendados
PC de 64 bitsIntel o AMD

  1. Haga una copia de sus archivos

    Copie sus documentos y fotos en un disco externo o en línea. Hágalo aunque conserve Windows: un error de disco ocurre rápido.

  2. Descargue la versión correcta

    ¿Una tarjeta gráfica NVIDIA (GeForce GTX 16xx, RTX)? Elija la versión NVIDIA; si no, la estándar. Para saberlo, en Windows: Administrador de dispositivos → Adaptadores de pantalla.

    Descargar

  3. Prepare la memoria USB

    Instale Fedora Media Writer (Windows o Mac), elija Seleccionar archivo .iso, luego su memoria y luego Escribir.

  4. Arranque desde la memoria

    Con la memoria conectada, encienda el ordenador pulsando varias veces la tecla de su marca y elija la memoria USB.

    MarcaTecla
    Acer, Dell, LenovoF12
    HPF9 / Esc
    ASUSF8 / Esc
    MSIF11
    OtraF12, F11 / Esc

    ¿No funciona? Desde Windows: Configuración → Sistema → Recuperación → Inicio avanzado → Reiniciar ahora y luego Usar un dispositivo.

  5. Pruebe y luego instale

    El escritorio de cosmic-blue arranca desde la memoria. Compruebe el Wi-Fi, el sonido y la pantalla. Si todo va bien, abra Install cosmic-blue en el escritorio.

  6. Elija dónde instalar

    Reemplazar Windows lo más sencillo

    En el instalador, elija el disco y libere espacio borrándolo todo. Se borra todo el disco.

    Junto a Windows

    Primero, en Windows, abra Administración de discos, haga clic derecho en la partición de Windows y elija Reducir volumen para liberar al menos 64 GB. El instalador usará ese espacio libre por sí solo.

    Antes de reducir, desactive el cifrado en Windows: Configuración → Privacidad y seguridad → Cifrado de dispositivo (o BitLocker). Un segundo disco solo para cosmic-blue es aún más sencillo.

    Después, cosmic-blue arranca por defecto. Para iniciar Windows, use la tecla del paso 4 y elija Windows Boot Manager.

  7. Versión NVIDIA: una pantalla azul en el primer reinicio

    Es normal y solo pasa una vez, con Secure Boot activado: permite cargar el controlador de NVIDIA. Use las flechas y Intro. La contraseña es cosmicblue (el teclado puede estar en QWERTY inglés).

    ¿Se le pasó? El escritorio arranca igual, sin el controlador de NVIDIA. Abra Herramientas de cosmic-blue → Controlador NVIDIA, pulse Permitir y reinicie.

  8. Bienvenida

    Tras el reinicio, cree su cuenta. Después se abre el recorrido, que le ayuda a configurarlo todo.
