COSMIC, listo para usar

El escritorio en Rust de System76, de los paquetes oficiales de Fedora, con un tema azul, paneles de vidrio esmerilado, iconos Tela circle, cursores Bibata y una pantalla de arranque a juego desde el primer momento.

Atómico y reversible

El sistema es una imagen de contenedor firmada. Las actualizaciones se descargan en segundo plano y se aplican en el siguiente arranque. Si algo se rompe, arranca la versión anterior.

La base de Universal Blue

La misma base y las mismas herramientas que Bluefin y Aurora: comandos ujust, Homebrew para las herramientas de línea de comandos, aplicaciones de Flathub en COSMIC Store y ujust install-dev-tools para las herramientas de desarrollo.

Instalación

Desde la ISO live

  1. Descarga la ISO live de arriba.
  2. Grábala en una memoria USB con Fedora Media Writer.
  3. Arranca desde la memoria: tendrás un escritorio COSMIC completo para probar. Secure Boot puede quedarse activado, no hace falta desactivarlo.
  4. Abre el instalador desde el icono del escritorio.
  5. Con Secure Boot activado, aparece una pantalla azul en el primer reinicio: elige Enroll MOK, luego Continue, y escribe la contraseña cosmicblue (distribución QWERTY). Así se puede cargar el controlador de NVIDIA.

¿Primera vez? La guía paso a paso explica la tecla de arranque, la instalación junto a Windows y la pantalla de NVIDIA.

Desde otro sistema bootc

¿Ya usas Bluefin, Aurora, Bazzite o un escritorio Fedora Atomic (Silverblue, Kinoite...)? Cambia directamente:

ujust enroll-secure-boot-key   # solo si Secure Boot está activado
sudo bootc switch ghcr.io/cosmic-blue-os/cosmic-blue:stable
sudo systemctl reboot

Tras el reinicio, cosmic-blue activa por sí solo la comprobación de firma de sus actualizaciones. stable avanza una vez por semana; cambia a testing para recibir cada versión diaria, o a dev para cada cambio en cuanto se fusiona.

Actualizaciones y vuelta atrás

ujust update          # actualizar ahora en lugar de esperar
sudo bootc rollback   # volver a la versión anterior en el próximo arranque

Imágenes firmadas

Cada imagen está firmada con cosign, y los sistemas instalados rechazan las actualizaciones sin firmar. Compruébalo a mano con cosign.pub:

cosign verify --key cosign.pub ghcr.io/cosmic-blue-os/cosmic-blue:stable

Las sumas de comprobación de las ISO y la lista de paquetes de cada imagen (SBOM) también están firmadas: consulta Comprobar las descargas.

Construido sobre Universal Blue, Bluefin, Fedora y COSMIC. cosmic-blue es un proyecto independiente, no afiliado a estos proyectos ni respaldado por ellos.
