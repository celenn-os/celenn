Documentación

Lo que necesitas saber para usar cosmic-blue en el día a día. cosmic-blue es una imagen atómica independiente construida sobre la base de Universal Blue: el sistema es de solo lectura y se actualiza como un todo, y tus aplicaciones y archivos viven aparte.

Actualizaciones y vuelta atrás

El sistema, las aplicaciones Flatpak, los paquetes de Homebrew y los AppImage añadidos con Gear Lever se actualizan solos en segundo plano. Una actualización del sistema se aplica en el siguiente arranque. Para actualizar ahora, o para desactivar las actualizaciones automáticas:

ujust update           # actualizar todo ahora
ujust toggle-updates   # activar o desactivar las actualizaciones automáticas

Si una actualización rompe algo, vuelve a la versión anterior. Sigue instalada hasta la próxima actualización, así que funciona sin conexión:

sudo bootc rollback    # usar la versión anterior en el próximo arranque
sudo systemctl reboot
sudo bootc status      # ver la versión actual y la anterior

¿El equipo ya no arranca, o la versión rota vuelve una y otra vez? Consulta Solución de problemas.

Instalar programas

Aplicaciones: COSMIC Store

Las aplicaciones gráficas llegan como Flatpak desde COSMIC Store, que muestra Flathub y las aplicaciones de COSMIC. Se actualizan con el sistema y no lo modifican.

AppImage: Gear Lever

Abre un AppImage descargado: Gear Lever lo añade a la lista de aplicaciones y lo mantiene al día.

Herramientas de línea de comandos: Homebrew

Las herramientas de línea de comandos se instalan en tu carpeta personal con Homebrew:

brew search ripgrep
brew install ripgrep

Paquetes de otras distribuciones: Distrobox

¿Necesitas un paquete que solo existe para otra distribución? Distrobox lo ejecuta en un contenedor que comparte tu carpeta personal:

distrobox create --name arch --image archlinux:latest
distrobox enter arch

Herramientas de desarrollo

El modo desarrollador añade Docker, Podman Desktop, VS Code y otros IDE, Lima y más. Elige lo que quieras en un menú:

ujust install-dev-tools

Impresoras, firmware, batería

Impresoras y escáneres

La mayoría de las impresoras de red y USB funcionan al instante, sin controlador. Para añadir una a mano, abre Configuración de impresión: hay controladores instalados para HP, Epson, Brother, Canon y otras. Escáner de documentos escanea con escáneres de red y USB.

Actualizaciones de firmware

La aplicación Firmware actualiza el firmware del equipo y de sus dispositivos (BIOS/UEFI, SSD, dock…), cuando el fabricante lo publica en fwupd.org. O desde la terminal:

ujust update-firmware

Batería del portátil

Una batería que siempre está enchufada dura más si no está siempre llena. En los portátiles que lo permiten, esto detiene la carga al 80 %:

ujust toggle-battery-limit

Comandos ujust

ujust ejecuta los atajos que trae el sistema. Escribe ujust para verlos todos, o ujust --choose para elegir uno en un menú. Cada comando install-… tiene su remove-…. Los más útiles:

ujust update
Actualizar ahora el sistema, las aplicaciones y los paquetes de Homebrew.
ujust toggle-updates
Activar o desactivar las actualizaciones automáticas.
ujust update-firmware
Instalar actualizaciones de firmware (BIOS/UEFI, SSD, dock…).
ujust switch-channel
Cambiar entre las imágenes stable (semanal, la predeterminada), testing (diaria) y dev (cada cambio fusionado).
ujust install-dev-tools
Herramientas de desarrollo, elegidas en un menú: Docker, VS Code, Podman Desktop…
ujust install-cli-tools
Herramientas de línea de comandos: bat, eza, fd, ripgrep, zoxide…
ujust install-microsoft-fonts
Fuentes de Microsoft: Arial, Times New Roman, Verdana…
ujust install-gaming
Steam y Heroic (Epic Games, GOG, Amazon).
ujust toggle-flatpark
Activar o desactivar FlatPark, una fuente extra de aplicaciones. Desactivado por defecto: sus aplicaciones no se revisan como las de Flathub.
ujust toggle-dark-mode
Cambiar entre el tema oscuro y el claro.
ujust reset-cosmic-theme
Recuperar el aspecto de cosmic-blue.
ujust reset-cosmic-config
Restablecer toda la configuración de COSMIC (se guarda una copia).
ujust toggle-battery-limit
Detener la carga del portátil al 80 % para que la batería dure más.
ujust toggle-tpm2
Desbloquear el disco cifrado con el chip TPM2, sin contraseña.
ujust enroll-secure-boot-key
NVIDIA con Secure Boot: registrar la clave del controlador.
ujust report-bug
Abrir un informe de error con los datos de tu sistema ya rellenados.

El aspecto

cosmic-blue trae un tema azul de COSMIC, paneles de vidrio esmerilado y fondos de pantalla, iconos y cursores propios. Cámbialo todo en Configuración. Si quieres recuperar el aspecto original:

ujust reset-cosmic-theme

Terminal

Cada nueva terminal muestra un mensaje de bienvenida con un consejo. fastfetch muestra la información del sistema. Para desactivar el mensaje de bienvenida, o volver a activarlo:

uwelcome toggle

Tus datos

Las actualizaciones solo sustituyen el sistema: tu carpeta personal, tus aplicaciones y su configuración se conservan, igual que tus cambios en /etc.

Cifrado del disco

El cifrado se elige en el instalador: en Installation Destination, marca Encrypt my data y elige una frase de contraseña. Hazlo en un portátil, que se puede perder o te pueden robar. No se puede activar más tarde sin reinstalar. Una vez instalado, el chip TPM2 puede desbloquear el disco al arrancar en lugar de la frase de contraseña:

ujust toggle-tpm2

Copias de seguridad

La aplicación Copias de seguridad (Déjà Dup) está instalada: guarda tu carpeta personal en un disco externo, una carpeta compartida en red o un almacenamiento en la nube, cifrada si quieres, y restaura archivos sueltos o todo. Para la terminal, también están instalados restic, borg y rclone.

Si vienes de otro sistema

Primero haz una copia de tus archivos (con Copias de seguridad, o copiándolos a un disco externo), instala cosmic-blue y luego cópialos de vuelta a tu carpeta personal. Vuelve a instalar tus aplicaciones desde COSMIC Store; las aplicaciones Flatpak guardan sus datos en ~/.var/app, que puedes copiar desde otro sistema que usara los mismos Flatpak.

Privacidad

cosmic-blue no recopila nada sobre ti. Lo que el sistema contacta por su cuenta:

  • Actualizaciones, una vez al día: las imágenes de cosmic-blue en GitHub, Flathub y el repositorio de aplicaciones de COSMIC, y Homebrew si lo usas (con sus estadísticas de uso desactivadas).
  • El recuento semanal anónimo de Fedora (rpm-ostree-countme): una petición por semana a los servidores de Fedora, con la versión de Fedora y la antigüedad aproximada del sistema pero sin ningún identificador, para que Fedora sepa cuántos sistemas la usan.
  • Firefox: la telemetría, los estudios y el contenido patrocinado están desactivados.
  • Tailscale está instalado, para sudo tailscale up: su servicio se ejecuta pero no se une a ninguna red hasta que inicias sesión.

Para detener el recuento de Fedora, o el servicio de Tailscale si no lo usas:

sudo systemctl mask --now rpm-ostree-countme.timer
sudo systemctl disable --now tailscaled.service

El cortafuegos (firewalld) está activado; la aplicación Cortafuegos cambia su configuración. Flatseal muestra y cambia a qué puede acceder cada aplicación Flatpak (archivos, dispositivos, red).

Comprobar las descargas

La suma de comprobación de cada ISO live está firmada con la clave del proyecto, cosign.pub. Descarga la ISO, su archivo .sha256 y su firma .sha256.sigstore.json en la misma carpeta y compruébalos con cosign (para la ISO de NVIDIA, usa los nombres cosmic-blue-nvidia-live-amd64):

cosign verify-blob --key cosign.pub \
  --bundle cosmic-blue-live-amd64.iso.sha256.sigstore.json \
  cosmic-blue-live-amd64.iso.sha256
sha256sum -c cosmic-blue-live-amd64.iso.sha256

Las imágenes del sistema también están firmadas, y los sistemas instalados rechazan las actualizaciones sin firmar. Cada imagen incluye además una lista firmada de sus paquetes (un SBOM SPDX):

cosign verify --key cosign.pub ghcr.io/cosmic-blue-os/cosmic-blue:stable
cosign verify-attestation --key cosign.pub --type spdxjson \
  --insecure-ignore-tlog=true ghcr.io/cosmic-blue-os/cosmic-blue:stable

Obtener ayuda

¿Algo no funciona? La página de solución de problemas cubre los problemas habituales.

¿Una pregunta, o algo que no queda claro? Pregunta en Discussions.

¿Has encontrado un error? Ejecuta esto en una terminal del equipo con el problema: recopila los datos del sistema (ningún dato personal) y abre un informe de error con ellos ya rellenados. Después cuenta qué hiciste y qué pasó.

ujust report-bug

cosmic-blue está construido sobre Universal Blue, Bluefin, Fedora y COSMIC. cosmic-blue es un proyecto independiente, no afiliado a estos proyectos ni respaldado por ellos.
