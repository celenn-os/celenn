Troubleshooting

Something went wrong? Most problems on Celenn OS can be undone: the previous system version stays installed, and your COSMIC settings can be put back to the defaults. Commands go in a terminal. See also the documentation.

The computer does not start after an update

  1. Turn the computer on and press Esc a few times (or hold Shift) until the boot menu shows.
  2. Pick the second entry, marked ostree:1: it is the version you had before the update.
  3. Once on the desktop, keep that version for the next boots too:
sudo bootc rollback

Then follow the next section so the broken version does not come back.

An update broke something

Go back to the version you had before. It stays installed until the next update, so this works offline:

sudo bootc rollback    # use the previous version on next boot
sudo systemctl reboot

Automatic updates would install the broken version again. Pause them, report the problem, and turn them back on once a fix is out:

ujust toggle-updates disable   # pause automatic updates
ujust toggle-updates enable    # turn them back on later

Go back further

Every build has its own version, like 44.20261110: sudo bootc status shows yours, and the releases page lists the weekly ones. You can install one of them, and come back to the normal updates later. On the NVIDIA image, write celenn-nvidia instead of Celenn OS.

sudo bootc switch --enforce-container-sigpolicy ghcr.io/celenn-os/celenn:44.20261110   # stay on this version
sudo bootc switch --enforce-container-sigpolicy ghcr.io/celenn-os/celenn:stable        # back to the weekly updates

The desktop does not start

Black screen, or back to the login screen after typing your password? Your COSMIC settings may be the cause.

  1. Press Ctrl+Alt+F3 to open a text console, and log in with your user name and password.
  2. Reset the COSMIC settings (your files and apps are not touched), then restart:
ujust reset-cosmic-config
sudo systemctl reboot

If it started after an update, go back to the previous version from the same console instead.

Look and settings

Lost the Celenn OS look, or a panel, dock or shortcut stopped behaving? Reset the appearance only, or every COSMIC setting. Log out and back in after either one.

ujust reset-cosmic-theme
Restore the colors, dark theme, icons, fonts and wallpaper. The panel, dock, keyboard and shortcuts are kept.
ujust reset-cosmic-config
Reset every COSMIC setting, but keep your keyboard layout and clock format. The old settings are moved to a ~/.config/cosmic.backup- folder, and the command prints how to bring them back.

An app does not work

Apps from the COSMIC Store are Flatpaks. Update them and repair the installed files first:

flatpak update
sudo flatpak repair

Still broken? Start the app with fresh settings. Find its ID, then move its data aside (put the folder back to undo):

flatpak list --app
mv ~/.var/app/org.example.App ~/.var/app/org.example.App.old

An app from FlatPark misbehaves? ujust toggle-flatpark off uninstalls its apps and turns FlatPark off.

Updates do not install

Run the update by hand to see the error, and check that automatic updates are on:

ujust update
ujust toggle-updates

Disk full? In Celenn OS Tools, Free up space, Clean up removes what nothing uses any more: Flatpak runtimes, unused container images, old Homebrew downloads. Your files, containers and their volumes stay. In a terminal: ujust clean-system.

NVIDIA driver

On the NVIDIA image with Secure Boot on, the driver only loads once its key is enrolled. Run the command below and restart: a blue screen asks to Enroll MOK, with the password celennos (typed on a QWERTY layout).

ujust enroll-secure-boot-key

Installed the standard image on a computer with an NVIDIA card? Switch to the NVIDIA image:

sudo bootc switch --enforce-container-sigpolicy ghcr.io/celenn-os/celenn-nvidia:stable

Report a problem

Run the first command below on the computer with the problem: it collects the system details (no personal data) and opens a bug report with them filled in. Say what you did and what happened. If the problem showed up during the previous boot, add the errors it logged (second command). Questions go to Discussions.

ujust report-bug
sudo journalctl -b -1 -p err --no-pager
