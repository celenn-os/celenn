Installation

Prêt en une demi-heure environ

Essayez d’abord depuis la clé USB : rien ne change sur l’ordinateur tant que vous ne lancez pas l’installation.

  1. Téléchargez l’ISO

    La version AMD ou Intel, ou la version NVIDIA avec le pilote déjà installé.

  2. Créez la clé USB

    Avec Fedora Media Writer, sous Windows, Mac ou Linux.

  3. Essayez, puis installez

    Le bureau démarre depuis la clé. Quand tout va bien, lancez l’installateur.

Déjà sur Bluefin, Aurora, Bazzite ou Fedora Atomic ? Basculez sur place. 
ujust enroll-secure-boot-key   # seulement si Secure Boot est activé
    sudo bootc switch ghcr.io/cosmic-blue-os/cosmic-blue:stable
    sudo systemctl reboot

Après le redémarrage, cosmic-blue active de lui-même la vérification de la signature de ses mises à jour. stable avance une fois par semaine ; passez à testing pour recevoir chaque build quotidien, ou à dev pour chaque changement dès sa fusion.
