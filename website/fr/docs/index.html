Documentation

Ce qu'il faut savoir pour utiliser cosmic-blue au quotidien. cosmic-blue est une image atomique indépendante, construite sur la base Universal Blue : le système est en lecture seule et mis à jour d'un bloc, vos applications et vos fichiers vivent à part.

Mises à jour et retour en arrière

Le système, les applications Flatpak, les paquets Homebrew et les AppImages ajoutées avec Gear Lever se mettent à jour seuls en arrière-plan. Une mise à jour du système s'applique au prochain démarrage. Pour mettre à jour tout de suite, ou couper les mises à jour automatiques :

ujust update           # tout mettre à jour maintenant
ujust toggle-updates   # activer ou couper les mises à jour automatiques

Si une mise à jour casse quelque chose, revenez à la version précédente. Elle reste installée jusqu'à la mise à jour suivante, donc cela marche sans réseau :

sudo bootc rollback    # utiliser la version précédente au prochain démarrage
sudo systemctl reboot
sudo bootc status      # voir la version actuelle et la précédente

L'ordinateur ne démarre plus, ou la version cassée revient sans cesse ? Voir Dépannage.

Installer des logiciels

Applications : COSMIC Store

Les applications graphiques sont des Flatpak, installées depuis le COSMIC Store, qui affiche Flathub et les applications COSMIC. Elles se mettent à jour avec le système et n'y touchent pas.

AppImages : Gear Lever

Ouvrez une AppImage téléchargée pour l'ajouter avec Gear Lever : il range le fichier dans un dossier à part, ajoute l'application à la liste des applications et la tient à jour.

Outils en ligne de commande : Homebrew

Les outils en ligne de commande s'installent dans votre dossier personnel avec Homebrew :

brew search ripgrep
brew install ripgrep

Paquets d'autres distributions : Distrobox

Besoin d'un paquet qui n'existe que pour une autre distribution ? Distrobox le fait tourner dans un conteneur qui partage votre dossier personnel :

distrobox create --name arch --image archlinux:latest
distrobox enter arch

Outils de développement

Le mode développeur ajoute Docker, Podman Desktop, VS Code et d'autres IDE, Lima et plus encore. Choisissez ce que vous voulez dans un menu :

ujust install-dev-tools

Commandes ujust

ujust lance les raccourcis fournis avec le système. Lancez ujust seul pour tous les lister, ou ujust --choose pour en choisir un dans un menu. Les plus utiles :

ujust update
Mettre à jour le système, les applications Flatpak et les paquets Homebrew tout de suite.
ujust toggle-updates
Activer ou couper les mises à jour automatiques.
ujust install-dev-tools
Installer des outils de développement à partir d'un menu : Docker, VS Code, Podman Desktop, Lima... Retirez-les avec ujust install-dev-tools remove.
ujust toggle-dark-mode
Passer du thème sombre au thème clair, et inversement.
ujust reset-cosmic-theme
Restaurer le style cosmic-blue : couleurs, icônes, fond d'écran.
ujust reset-cosmic-config
Remettre tous les réglages COSMIC par défaut de cosmic-blue (une sauvegarde est gardée).
ujust install-cli-tools
Installer des outils en ligne de commande pratiques avec Homebrew (bat, eza, fd, ripgrep, zoxide, yq…) et, si vous le souhaitez, des raccourcis qui les utilisent dans le terminal. Pour les retirer : ujust install-cli-tools remove.
ujust install-microsoft-fonts
Télécharger les polices de base de Microsoft (Arial, Times New Roman, Verdana…) pour votre compte, après avoir accepté leur licence.
ujust install-gaming
Installer Steam et Heroic (les jeux d'Epic Games, GOG et Amazon) depuis Flathub. Retirez-les avec ujust install-gaming remove ; vos jeux et sauvegardes sont conservés.
ujust toggle-flatpark
Activer ou désactiver FlatPark, une source d'applications supplémentaire absentes de Flathub. Il est désactivé par défaut car ses applications ne sont pas vérifiées comme celles de Flathub ; une fois activé, les applications aussi présentes sur Flathub viennent toujours de Flathub. On peut aussi l'ajouter ou le retirer dans COSMIC Store, sous Dépôts logiciels.
ujust switch-channel
Suivre stable (une nouvelle image par semaine, après plus de tests ; le choix par défaut) ou latest (chaque version quotidienne) : ujust switch-channel latest. Seul, il affiche le canal utilisé.
ujust toggle-tpm2
Déverrouiller un disque chiffré avec la puce TPM2 au lieu d'un mot de passe.
ujust enroll-secure-boot-key
Image NVIDIA avec Secure Boot : enregistrer la clé qui permet de charger le pilote.
ujust report-bug
Ouvrir un rapport de bug avec les informations du système déjà remplies.

Apparence

cosmic-blue arrive avec un thème COSMIC bleu, des panneaux en verre dépoli, des fonds d'écran, icônes et curseurs cosmic-blue. Tout se change dans les Paramètres. Pour retrouver le style d'origine :

ujust reset-cosmic-theme

Terminal

Chaque nouveau terminal affiche un message d'accueil avec une astuce. fastfetch affiche les informations du système. Pour désactiver le message d'accueil, ou le réactiver :

uwelcome toggle

Vos données

Les mises à jour ne remplacent que le système : votre dossier personnel, vos applications et leurs réglages sont conservés, ainsi que vos modifications de /etc.

Chiffrement du disque

Le chiffrement se choisit dans l'installateur : dans Destination de l'installation, cochez Chiffrer mes données et choisissez une phrase de passe. Faites-le sur un portable, qui peut être perdu ou volé. Il ne peut pas être activé plus tard sans réinstaller. Une fois installé, la puce TPM2 peut déverrouiller le disque au démarrage à la place de la phrase de passe :

ujust toggle-tpm2

Sauvegardes

L'application Sauvegardes (Déjà Dup) est installée : elle enregistre votre dossier personnel sur un disque externe, un partage réseau ou un stockage en ligne, chiffré si vous le souhaitez, et restaure un fichier ou tout le dossier. En ligne de commande, restic, borg et rclone sont aussi installés.

Venir d'un autre système

Sauvegardez d'abord vos fichiers (Sauvegardes, ou une copie sur un disque externe), installez cosmic-blue, puis recopiez-les dans votre dossier personnel. Réinstallez vos applications depuis COSMIC Store ; les applications Flatpak gardent leurs données dans ~/.var/app, que vous pouvez recopier depuis un autre système qui utilisait les mêmes Flatpaks.

Vie privée

cosmic-blue ne collecte rien sur vous. Ce que le système contacte de lui-même :

  • Les mises à jour, une fois par jour : les images cosmic-blue sur GitHub, Flathub et le dépôt d'applications COSMIC, et Homebrew si vous l'utilisez (avec les statistiques d'utilisation de Homebrew désactivées).
  • Le comptage anonyme hebdomadaire de Fedora (rpm-ostree-countme) : une requête par semaine aux serveurs de Fedora, avec la version de Fedora et l'âge approximatif du système mais sans identifiant, pour que Fedora sache combien de systèmes l'utilisent.
  • Firefox : télémétrie, études et contenus sponsorisés sont désactivés.
  • Tailscale est installé, pour sudo tailscale up : son service tourne mais ne rejoint aucun réseau tant que vous ne vous êtes pas connecté.

Pour arrêter le comptage de Fedora, ou le service Tailscale si vous ne l'utilisez pas :

sudo systemctl mask --now rpm-ostree-countme.timer
sudo systemctl disable --now tailscaled.service

Le pare-feu (firewalld) est actif ; l'application Pare-feu change ses réglages. Flatseal montre et change ce à quoi chaque application Flatpak a accès (fichiers, périphériques, réseau).

Vérifier les téléchargements

La somme de contrôle de chaque ISO live est signée avec la clé du projet, cosign.pub. Téléchargez l'ISO, son fichier .sha256 et sa signature .sha256.sigstore.json dans le même dossier, puis vérifiez-les avec cosign (pour l'ISO NVIDIA, utilisez les noms cosmic-blue-nvidia-live-amd64) :

cosign verify-blob --key cosign.pub \
  --bundle cosmic-blue-live-amd64.iso.sha256.sigstore.json \
  cosmic-blue-live-amd64.iso.sha256
sha256sum -c cosmic-blue-live-amd64.iso.sha256

Les images système sont signées elles aussi, et un système installé refuse les mises à jour non signées. Chaque image porte aussi la liste signée de ses paquets (un SBOM SPDX) :

cosign verify --key cosign.pub ghcr.io/cosmic-blue-os/cosmic-blue:stable
cosign verify-attestation --key cosign.pub --type spdxjson \
  --insecure-ignore-tlog=true ghcr.io/cosmic-blue-os/cosmic-blue:stable

Obtenir de l'aide

Quelque chose ne marche pas ? La page de dépannage couvre les problèmes courants.

Une question, ou quelque chose de pas clair ? Posez-la dans les Discussions (en anglais de préférence).

Un bug ? Lancez ceci dans un terminal sur l'ordinateur concerné : la commande rassemble les informations du système (aucune donnée personnelle) et ouvre un rapport de bug déjà rempli avec elles. Dites ensuite ce que vous avez fait et ce qui s'est passé.

ujust report-bug

cosmic-blue est construit sur Universal Blue, Bluefin, Fedora et COSMIC. cosmic-blue est un projet indépendant, sans lien avec ces projets ni soutien de leur part.
