COSMIC, sofort startklar

Der Rust-Desktop von System76 aus den offiziellen Fedora-Paketen, mit einem blauen Theme, Milchglas-Leisten, Tela-circle-Icons, Bibata-Cursorn und einem passenden Startbildschirm, direkt nach der Installation.

Atomar und umkehrbar

Das System ist ein signiertes Container-Image. Updates werden im Hintergrund geladen und beim nächsten Start angewendet. Geht etwas kaputt, starten Sie die vorherige Version.

Die Basis von Universal Blue

Dieselbe Basis und dieselben Werkzeuge wie Bluefin und Aurora: ujust-Befehle, Homebrew für Kommandozeilen-Tools, Flathub-Apps im COSMIC Store und ujust install-dev-tools für Entwicklerwerkzeuge.

Installation

Mit der Live-ISO

  1. Laden Sie oben die Live-ISO herunter.
  2. Schreiben Sie sie mit Fedora Media Writer auf einen USB-Stick.
  3. Starten Sie vom Stick: Sie erhalten einen vollständigen COSMIC-Desktop zum Ausprobieren. Secure Boot kann eingeschaltet bleiben, Sie müssen es nicht abschalten.
  4. Starten Sie das Installationsprogramm über das Symbol auf dem Desktop.
  5. Mit Secure Boot erscheint beim ersten Neustart ein blauer Bildschirm: Wählen Sie Enroll MOK, dann Continue, und geben Sie das Passwort cosmicblue ein (QWERTY-Belegung). So kann der NVIDIA-Treiber geladen werden.

Von einem anderen bootc-System

Schon auf Bluefin, Aurora, Bazzite oder einem Fedora-Atomic-Desktop (Silverblue, Kinoite...)? Wechseln Sie direkt:

ujust enroll-secure-boot-key   # nur wenn Secure Boot an ist
sudo bootc switch ghcr.io/cosmic-blue-os/cosmic-blue:stable
sudo systemctl reboot

Nach dem Neustart schaltet cosmic-blue die Signaturprüfung seiner Updates selbst ein. stable wird einmal pro Woche aktualisiert; wechseln Sie zu testing für jeden täglichen Build oder zu dev für jede Änderung, sobald sie übernommen ist.

Updates und Zurücksetzen

ujust update          # jetzt aktualisieren, statt zu warten
sudo bootc rollback   # beim nächsten Start zur vorherigen Version zurück

Signierte Images

Jedes Image ist mit cosign signiert, und installierte Systeme lehnen unsignierte Updates ab. Prüfen Sie es selbst mit cosign.pub:

cosign verify --key cosign.pub ghcr.io/cosmic-blue-os/cosmic-blue:stable

Auch die Prüfsummen der ISOs und die Paketliste jedes Images (SBOM) sind signiert: siehe Downloads prüfen.

Aufgebaut auf Universal Blue, Bluefin, Fedora und COSMIC. cosmic-blue ist ein unabhängiges Projekt, nicht mit diesen Projekten verbunden und nicht von ihnen unterstützt.
