Installation

In etwa einer halben Stunde bereit

Probieren Sie es zuerst vom USB-Stick aus: Am Computer ändert sich nichts, bis Sie die Installation starten.

Live-ISO herunterladen

Ältere NVIDIA-Karte? Nehmen Sie die Version für AMD oder Intel, die den freien Treiber nutzt.

x86-64 · SHA-256 · Signatur

  1. ISO herunterladen

    Die Version für AMD oder Intel, oder die NVIDIA-Version mit bereits installiertem Treiber.

  2. USB-Stick erstellen

    Mit Fedora Media Writer, unter Windows, Mac oder Linux.

  3. Ausprobieren, dann installieren

    Der Desktop startet vom Stick. Wenn alles läuft, starten Sie das Installationsprogramm.

Schon auf Bluefin, Aurora, Bazzite oder Fedora Atomic? Direkt umsteigen. 
ujust enroll-secure-boot-key   # nur wenn Secure Boot an ist
sudo bootc switch ghcr.io/celenn-os/celenn:stable
sudo systemctl reboot

Nach dem Neustart schaltet cosmic-blue die Signaturprüfung seiner Updates selbst ein. stable wird einmal pro Woche aktualisiert; wechseln Sie zu testing für jeden täglichen Build oder zu dev für jede Änderung, sobald sie übernommen ist.

Fragen

Bevor Sie wechseln

Ist es kostenlos?

Ja. cosmic-blue und die Apps, die es vorschlägt, sind kostenlos und quelloffen. Kein Konto, kein Abo, keine Werbung.

Muss ich Linux kennen oder ein Terminal benutzen?

Nein. Eine geführte Tour richtet bei der ersten Anmeldung alles ein, danach erledigen cosmic-blue Werkzeuge, Updates und der Jugendschutz den Rest ohne einen einzigen Befehl.

Funktioniert mein Computer damit?

Starten Sie cosmic-blue vom USB-Stick: Der Willkommensbildschirm prüft WLAN, Ton, Grafikkarte, Arbeitsspeicher und Festplatte, bevor Sie installieren. Nötig sind 64 GB freier Speicherplatz, mit 8 GB Arbeitsspeicher läuft es angenehm.

Kann ich zu Windows zurück?

Das Ausprobieren vom USB-Stick ändert nichts am Computer. Sie können es auch neben Windows installieren und beim Start wählen. Wenn Sie Windows ersetzen, heißt zurückgehen, Windows von seinem eigenen USB-Stick neu zu installieren.

Sind meine Dateien sicher?

Die Installation neben Windows rührt dessen Dateien nicht an, sichern Sie sie trotzdem vorher. Nach der Installation speichert Déjà Dup Datensicherungen Ihre Dateien auf einer Festplatte oder in einem Online-Konto.

Laufen meine Windows-Programme?

Windows-Programme (.exe) lassen sich hier nicht installieren, aber fast jedes hat eine kostenlose Alternative, oft schon installiert. Siehe Ihre Windows- und Mac-Programme, hier.

Laufen meine Spiele?

Steam und Heroic lassen sich in der Tour installieren, und die meisten Windows-Spiele laufen mit Proton in Steam. Manche Online-Spiele mit Anti-Cheat laufen nicht: Prüfen Sie Ihres auf ProtonDB. Mit einer NVIDIA-Karte nehmen Sie die NVIDIA-Version.

Und wenn ein Update etwas kaputt macht?

Jedes Update wird getestet, bevor es Sie erreicht, und wirkt erst beim nächsten Neustart. Wenn etwas schiefgeht, kehrt die App Updates mit einem Klick zur vorherigen Version zurück.

Wo bekomme ich Hilfe?

Die Seite Fehlerbehebung deckt die häufigen Probleme ab. Für alles andere fragen Sie in den Discussions. cosmic-blue ist ein junges, unabhängiges Projekt.
