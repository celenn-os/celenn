Installation

In etwa einer halben Stunde bereit

Probieren Sie es zuerst vom USB-Stick aus: Am Computer ändert sich nichts, bis Sie die Installation starten.

  1. ISO herunterladen

    Die Version für AMD oder Intel, oder die NVIDIA-Version mit bereits installiertem Treiber.

  2. USB-Stick erstellen

    Mit Fedora Media Writer, unter Windows, Mac oder Linux.

  3. Ausprobieren, dann installieren

    Der Desktop startet vom Stick. Wenn alles läuft, starten Sie das Installationsprogramm.

Schon auf Bluefin, Aurora, Bazzite oder Fedora Atomic? Direkt umsteigen. 
ujust enroll-secure-boot-key   # nur wenn Secure Boot an ist
    sudo bootc switch ghcr.io/cosmic-blue-os/cosmic-blue:stable
    sudo systemctl reboot

Nach dem Neustart schaltet cosmic-blue die Signaturprüfung seiner Updates selbst ein. stable wird einmal pro Woche aktualisiert; wechseln Sie zu testing für jeden täglichen Build oder zu dev für jede Änderung, sobald sie übernommen ist.
