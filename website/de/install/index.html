cosmic-blue Schritt für Schritt installieren

Rechnen Sie mit einer halben Stunde. Sie können cosmic-blue zuerst vom USB-Stick ausprobieren: Am Computer ändert sich nichts, bis Sie die Installation starten.

USB-Stick, 8 GBwird gelöscht
64 GB Speicherplatz128 GB empfohlen
4 GB Arbeitsspeicher8 GB empfohlen
64-Bit-PCIntel oder AMD

  1. Sichern Sie Ihre Dateien

    Kopieren Sie Dokumente und Fotos auf eine externe Festplatte oder online. Auch wenn Sie Windows behalten: Ein Fehler an der Festplatte passiert schnell.

  2. Laden Sie die richtige Version herunter

    Eine NVIDIA-Grafikkarte (GeForce GTX 16xx, RTX)? Nehmen Sie die NVIDIA-Version, sonst die Standardversion. Nachsehen unter Windows: Geräte-Manager → Grafikkarten.

    Herunterladen

  3. Erstellen Sie den USB-Stick

    Installieren Sie Fedora Media Writer (Windows oder Mac), wählen Sie .iso-Datei auswählen, dann Ihren Stick, dann Schreiben.

  4. Starten Sie vom Stick

    Stecken Sie den Stick ein, schalten Sie den Computer ein, drücken Sie mehrmals die Taste Ihrer Marke und wählen Sie den USB-Stick.

    MarkeTaste
    Acer, Dell, LenovoF12
    HPF9 / Esc
    ASUSF8 / Esc
    MSIF11
    AndereF12, F11 / Esc

    Klappt nicht? Unter Windows: Einstellungen → System → Wiederherstellung → Erweiterter Start → Jetzt neu starten, dann Ein Gerät verwenden.

  5. Ausprobieren, dann installieren

    Der cosmic-blue-Desktop startet vom Stick. Prüfen Sie WLAN, Ton und Bildschirm. Wenn alles passt, öffnen Sie Install cosmic-blue auf dem Desktop.

  6. Wählen Sie, wohin installiert wird

    Windows ersetzen am einfachsten

    Wählen Sie im Installationsprogramm die Festplatte und geben Sie Platz frei, indem Sie alles löschen. Die ganze Festplatte wird gelöscht.

    Neben Windows

    Öffnen Sie zuerst unter Windows die Datenträgerverwaltung, klicken Sie mit der rechten Maustaste auf die Windows-Partition und wählen Sie Volume verkleinern, um mindestens 64 GB freizugeben. Das Installationsprogramm nutzt diesen freien Platz dann von selbst.

    Schalten Sie vor dem Verkleinern die Verschlüsselung in Windows aus: Einstellungen → Datenschutz und Sicherheit → Geräteverschlüsselung (oder BitLocker). Eine zweite Festplatte nur für cosmic-blue ist noch einfacher.

    cosmic-blue startet danach standardmäßig. Für Windows nutzen Sie die Taste aus Schritt 4 und wählen Windows Boot Manager.

  7. NVIDIA-Version: ein blauer Bildschirm beim ersten Neustart

    Das ist normal und passiert nur einmal, wenn Secure Boot an ist: Er erlaubt den NVIDIA-Treiber. Nutzen Sie die Pfeiltasten und Enter. Das Passwort ist cosmicblue (die Tastatur kann auf QWERTY stehen: y und z sind vertauscht).

    Verpasst? Der Desktop startet trotzdem, ohne NVIDIA-Treiber. Öffnen Sie cosmic-blue Werkzeuge → NVIDIA-Treiber, klicken Sie auf Erlauben und starten Sie neu.

  8. Willkommen

    Legen Sie nach dem Neustart Ihr Konto an. Danach öffnet sich die Tour und hilft beim Einrichten.
