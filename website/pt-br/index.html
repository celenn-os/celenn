COSMIC, pronto para usar

O desktop em Rust da System76, dos pacotes oficiais do Fedora, com um tema azul, painéis de vidro fosco, ícones Tela circle, cursores Bibata e uma tela de inicialização combinando, logo de cara.

Atômico e reversível

O sistema é uma imagem de contêiner assinada. As atualizações são baixadas em segundo plano e aplicadas na próxima inicialização. Se algo quebrar, inicie a versão anterior.

A base do Universal Blue

A mesma base e as mesmas ferramentas do Bluefin e do Aurora: comandos ujust, Homebrew para ferramentas de linha de comando, aplicativos do Flathub na COSMIC Store e ujust install-dev-tools para ferramentas de desenvolvimento.

Instalação

Pela ISO live

  1. Baixe a ISO live acima.
  2. Grave-a em um pendrive com o Fedora Media Writer.
  3. Inicie pelo pendrive: você terá um desktop COSMIC completo para experimentar. O Secure Boot pode continuar ativado, não é preciso desligá-lo.
  4. Abra o instalador pelo ícone na área de trabalho.
  5. Com o Secure Boot ativado, uma tela azul aparece na primeira reinicialização: escolha Enroll MOK, depois Continue, e digite a senha cosmicblue (layout QWERTY). Isso permite carregar o driver da NVIDIA.

Primeira vez? O guia passo a passo explica a tecla de inicialização, a instalação ao lado do Windows e a tela da NVIDIA.

A partir de outro sistema bootc

Já usa Bluefin, Aurora, Bazzite ou um desktop Fedora Atomic (Silverblue, Kinoite...)? Mude direto:

ujust enroll-secure-boot-key   # só se o Secure Boot estiver ativado
sudo bootc switch ghcr.io/cosmic-blue-os/cosmic-blue:stable
sudo systemctl reboot

Depois da reinicialização, o cosmic-blue ativa sozinho a verificação de assinatura das suas atualizações. stable avança uma vez por semana; mude para testing para receber cada versão diária, ou para dev para cada mudança assim que ela for integrada.

Atualizações e reversão

ujust update          # atualizar agora em vez de esperar
sudo bootc rollback   # voltar para a versão anterior na próxima inicialização

Imagens assinadas

Cada imagem é assinada com o cosign, e os sistemas instalados recusam atualizações sem assinatura. Verifique manualmente com cosign.pub:

cosign verify --key cosign.pub ghcr.io/cosmic-blue-os/cosmic-blue:stable

As somas de verificação das ISOs e a lista de pacotes de cada imagem (SBOM) também são assinadas: veja Verificar os downloads.
