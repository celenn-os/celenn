Placa NVIDIA mais antiga? Escolha a versão AMD ou Intel, que usa o driver de código aberto.

x86-64 · SHA-256 · assinatura

  1. Baixe a ISO

    A versão para AMD ou Intel, ou a versão NVIDIA com o driver já instalado.

  2. Crie o pendrive

    Com o Fedora Media Writer, no Windows, Mac ou Linux.

  3. Experimente e depois instale

    O desktop inicia pelo pendrive. Quando tudo estiver funcionando, abra o instalador.

Já usa Bluefin, Aurora, Bazzite ou Fedora Atomic? Mude sem reinstalar. 
ujust enroll-secure-boot-key   # só se o Secure Boot estiver ativado
sudo bootc switch ghcr.io/celenn-os/celenn:stable
sudo systemctl reboot

Depois da reinicialização, o Celenn OS ativa sozinho a verificação de assinatura das suas atualizações. stable avança uma vez por semana; mude para testing para receber cada versão diária, ou para dev para cada mudança assim que ela for integrada.

Perguntas

Antes de mudar

É gratuito?

Sim. O Celenn OS e os aplicativos que ele sugere são gratuitos e de código aberto. Sem conta, sem assinatura, sem anúncios.

Preciso conhecer Linux ou usar um terminal?

Não. Um tour guiado configura tudo no primeiro login, e depois Ferramentas do Celenn OS, Atualizações e o controle parental fazem o resto sem um único comando.

Meu computador vai funcionar?

Inicie o Celenn OS pelo pendrive: a tela de boas-vindas verifica Wi-Fi, som, placa de vídeo, memória e disco antes de instalar. São necessários 64 GB livres no disco, e com 8 GB de memória tudo roda com folga.

Posso voltar para o Windows?

Testar pelo pendrive não muda nada no computador. Você também pode instalar ao lado do Windows e escolher ao ligar. Se você substituir o Windows, voltar significa reinstalar o Windows com o pendrive dele.

Meus arquivos estão seguros?

Instalar ao lado do Windows não mexe nos arquivos dele, mas faça backup antes mesmo assim. Depois de instalado, o Backups Déjà Dup salva seus arquivos em um disco ou em uma conta online.

Meus programas do Windows funcionam?

Programas do Windows (.exe) não se instalam aqui, mas quase todos têm um equivalente gratuito, muitas vezes já instalado. Veja seus programas do Windows e do Mac, aqui.

Meus jogos funcionam?

Steam e Heroic se instalam pelo tour, e a maioria dos jogos de Windows roda com o Proton, no Steam. Alguns jogos online com anti-cheat não: confira o seu no ProtonDB. Com uma placa NVIDIA, escolha a versão NVIDIA.

E se uma atualização quebrar algo?

Cada atualização é testada antes de chegar até você e só é aplicada na próxima reinicialização. Se algo der errado, o aplicativo Atualizações volta para a versão anterior com um clique.

Onde encontro ajuda?

A página de solução de problemas cobre os problemas comuns. Para todo o resto, pergunte nas Discussions. O Celenn OS é um projeto jovem e independente.
