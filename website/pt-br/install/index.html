Instalar o cosmic-blue passo a passo

Reserve meia hora. Você pode experimentar o cosmic-blue primeiro pelo pen drive: nada muda no computador até você iniciar a instalação.

Pen drive de 8 GBserá apagado
64 GB de disco128 GB recomendados
4 GB de memória8 GB recomendados
PC de 64 bitsIntel ou AMD

  1. Faça backup dos seus arquivos

    Copie documentos e fotos para um disco externo ou para a nuvem. Faça isso mesmo mantendo o Windows: um erro no disco acontece rápido.

  2. Baixe a versão certa

    Placa de vídeo NVIDIA (GeForce GTX 16xx, RTX)? Escolha a versão NVIDIA; senão, a padrão. Para saber, no Windows: Gerenciador de Dispositivos → Adaptadores de vídeo.

    Baixar

  3. Prepare o pen drive

    Instale o Fedora Media Writer (Windows ou Mac), escolha Selecionar arquivo .iso, depois o pen drive e depois Gravar.

  4. Inicie pelo pen drive

    Com o pen drive conectado, ligue o computador apertando várias vezes a tecla da sua marca e escolha o pen drive.

    MarcaTecla
    Acer, Dell, LenovoF12
    HPF9 / Esc
    ASUSF8 / Esc
    MSIF11
    OutraF12, F11 / Esc

    Não funcionou? No Windows: Configurações → Sistema → Recuperação → Inicialização avançada → Reiniciar agora e depois Usar um dispositivo.

  5. Experimente e depois instale

    A área de trabalho do cosmic-blue inicia pelo pen drive. Teste o Wi-Fi, o som e a tela. Se estiver tudo certo, abra Install cosmic-blue na área de trabalho.

  6. Escolha onde instalar

    Substituir o Windows o mais simples

    No instalador, escolha o disco e libere espaço apagando tudo. O disco inteiro é apagado.

    Ao lado do Windows

    Primeiro, no Windows, abra o Gerenciamento de Disco, clique com o botão direito na partição do Windows e escolha Diminuir volume para liberar pelo menos 64 GB. O instalador usa esse espaço livre sozinho.

    Antes de diminuir, desative a criptografia no Windows: Configurações → Privacidade e segurança → Criptografia do dispositivo (ou BitLocker). Um segundo disco só para o cosmic-blue é ainda mais simples.

    Depois, o cosmic-blue inicia por padrão. Para abrir o Windows, use a tecla do passo 4 e escolha Windows Boot Manager.

  7. Versão NVIDIA: uma tela azul no primeiro reinício

    É normal e só acontece uma vez, com o Secure Boot ligado: ela libera o driver da NVIDIA. Use as setas e Enter. A senha é cosmicblue (o teclado pode estar no padrão americano).

    Perdeu a tela? A área de trabalho inicia mesmo assim, sem o driver da NVIDIA. Abra Ferramentas do cosmic-blue → Computador, clique em Permitir e reinicie.

  8. Boas-vindas

    Depois do reinício, crie sua conta. Em seguida abre o tour, que ajuda a configurar tudo.

O cosmic-blue é construído sobre Universal Blue, Bluefin, Fedora e COSMIC. O cosmic-blue é um projeto independente, sem afiliação nem endosso desses projetos.
