Why cosmic-blue?

cosmic-blue starts from the same foundations as Fedora COSMIC Atomic: Fedora, the COSMIC desktop from Fedora's official packages, and an atomic system. It adds tools made for families and for people new to Linux, all usable without a terminal.

A guided tour at first login

At an account's first login, a few pages help you find your way around:

  • The desktop layout, the wallpaper and the account picture.
  • Software for what you do: office, games, graphics, video, development.
  • Getting your files back from a phone or another computer.
  • A password manager and the moves worth knowing.

Open it again at any time with the First steps app.

Complete parental controls

Each child has their own account, set up by a parent in a single app.

  • Screen time per day, different on weekdays and at the weekend.
  • Bedtime: no computer at night.
  • Apps approved by a parent: the others do not open.
  • A family web filter that blocks adult websites.
  • “More time”: the child asks, a parent agrees with their password.
  • Time spent this week and the most used apps.

System tools, without a terminal

The cosmic-blue Tools app brings together what would take a command elsewhere:

  • Updates.
  • Maintenance: trash, disk space, backups.
  • Information about the computer, useful when asking for help.
  • Extra software, installed in one click.
  • Appearance and help.

Ready to use

  • Flathub in the COSMIC Store, with Firefox, Thunderbird and everyday apps already installed.
  • Audio and video codecs, printing and scanning.
  • Automatic backups with Déjà Dup.
  • LocalSend to swap files with a phone.
  • An NVIDIA edition with the driver already installed, Secure Boot on.

Safe updates

Updates download in the background and apply at the next restart: the system is never half updated.

Each version is tested before release (startup, update from the previous version, rollback), then signed. If something goes wrong, just start the previous version.

Good to know

cosmic-blue is a young, small project: it has fewer users and testers than Fedora. If you want COSMIC as Fedora ships it, Fedora COSMIC Atomic is a very good choice.
