Install cosmic-blue, step by step

Allow half an hour. You can try cosmic-blue from the USB stick first: nothing changes on the computer until you start the installer.

8 GB USB stickit will be erased
64 GB of disk128 GB recommended
4 GB of memory8 GB recommended
64-bit PCIntel or AMD

  1. Back up your files

    Copy your documents and photos to an external drive or online. Do it even if you keep Windows: a disk mistake happens quickly.

  2. Download the right version

    An NVIDIA graphics card (GeForce GTX 16xx, RTX)? Take the NVIDIA version, otherwise the standard one. To find out, in Windows: Device Manager → Display adapters.

    Download

  3. Make the USB stick

    Install Fedora Media Writer (Windows or Mac), choose Select .iso file, then your stick, then Write.

  4. Start from the stick

    With the stick plugged in, turn the computer on while pressing your brand's key a few times, then pick the USB stick.

    BrandKey
    Acer, Dell, LenovoF12
    HPF9 / Esc
    ASUSF8 / Esc
    MSIF11
    OtherF12, F11 / Esc

    Does not work? From Windows: Settings → System → Recovery → Advanced startup → Restart now, then Use a device.

  5. Try it, then install

    The cosmic-blue desktop starts from the stick. Check the Wi-Fi, the sound and the screen. When all is well, open Install cosmic-blue on the desktop.

  6. Choose where to install

    Replace Windows the simplest

    In the installer, pick the disk and choose to free up space by deleting everything. The whole disk is erased.

    Next to Windows

    First, in Windows, open Disk Management, right-click the Windows partition and Shrink Volume to free at least 64 GB. The installer then uses that free space by itself.

    Before shrinking, turn off the encryption in Windows: Settings → Privacy & security → Device encryption (or BitLocker). A second disk only for cosmic-blue is even simpler.

    cosmic-blue then starts by default. To start Windows, use the key of step 4 and pick Windows Boot Manager.

  7. NVIDIA version: a blue screen at the first restart

    This is normal and happens only once, when Secure Boot is on: it lets the NVIDIA driver load. Use the arrow keys and Enter. The password is cosmicblue (the keyboard may be in QWERTY).

    Missed it? The desktop still starts, without the NVIDIA driver. Open cosmic-blue Tools → Computer, click Allow, then restart.

  8. Welcome

    After the restart, create your account. The tour then opens and helps you set everything up.
