Install

Ready in about half an hour

Try it from the USB stick first: nothing changes on the computer until you start the installation.

Download cosmic-blue

Live ISO: try it before installing.

Graphics card
Download the live ISO

Older NVIDIA card? Take the AMD or Intel version, which uses the open source driver.

x86-64 · SHA-256 · signature

  1. Download the ISO

    The AMD or Intel edition, or the NVIDIA one with the driver already installed.

  2. Make the USB stick

    With Fedora Media Writer, on Windows, Mac or Linux.

  3. Try, then install

    The desktop starts from the stick. When everything works, start the installer.

Already on Bluefin, Aurora, Bazzite or Fedora Atomic? Switch in place. 
ujust enroll-secure-boot-key   # only if Secure Boot is on
    sudo bootc switch ghcr.io/cosmic-blue-os/cosmic-blue:stable
    sudo systemctl reboot

After the reboot, cosmic-blue turns on the signature check of its updates by itself. stable moves once a week; switch to testing to get every daily build, or dev for every change as soon as it is merged.
